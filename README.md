## 📖 Overview

This repository hosts my coursework, programming assignments, and modular deep learning models built from scratch for the **Deep Learning Specialization** offered by **DeepLearning.AI** and taught by **Dr. Andrew Ng** on **Coursera**.

The specialization consists of five foundational courses designed to master the fundamentals of Deep Learning, build and optimize deep neural architectures from the ground up, and apply them across computer vision, natural language processing, and sequence modeling.

## 🌟 Spotlight: Course 1 — Neural Networks and Deep Learning

For a comprehensive technical breakdown, mathematical formulations, matrix dimensions cheatsheet, and code implementation details, please visit the **[Course 1 Detailed Documentation](./Course1-Neural-Networks-and-Deep-Learning/README.md)**.

### Summary of Course 1 Assignments & Milestones:
* **Week 1**: Introduction to Deep Learning, economic & computational drivers of deep learning.
* **Week 2**:
  * `W2A1`: **Python Basics with NumPy** (vectorization, broadcasting, row normalization, softmax, L1/L2 loss).
  * `W2A2`: **Logistic Regression as a Neural Network** (vectorized single-neuron Cat Classifier, **70.0% test accuracy**).
* **Week 3**:
  * `W3A1`: **Planar Data Classification with One Hidden Layer** (2-layer shallow NN, tanh activation, symmetry breaking via random initialization, **90.0% accuracy**).
* **Week 4**:
  * `W4A1`: **Building Your Deep Neural Network Step by Step** (modular L-layer forward/backward framework, ReLU & Sigmoid activations, gradient caches).
  * `W4A2`: **Deep Neural Network for Image Classification** (applied modular L-layer deep network to Cat vs. Non-Cat benchmark, boosting test accuracy to **80.0%**).

## 🛠️ Tech Stack & Environment

* **Language**: Python 3.x
* **Core Libraries**: NumPy, SciPy, Matplotlib, h5py, Pillow (PIL)
* **Environment**: Jupyter Notebook / JupyterLab
* **Design Pattern**: First-principles vectorized implementation (matrix operations via NumPy without high-level abstractions like PyTorch or TensorFlow).
